================================================================================
EXECUTIVE SUMMARY
================================================================================

The documentation describes a complete Qubes-like system reaching Milestone 7
(usable desktop with VM manager + SPICE). The code currently implements
Milestone 2–3 (VMs boot and run on host NAT). There is a significant gap
between the spec and implementation.

Current code WILL BUILD and RUN, but it reaches only ~40% of the documented goal.

WHAT WON'T WORK / IS MISSING
================================================================================

Security / Isolation:
  ❌ No fw VM (firewall rules)
  ❌ No net VM (dedicated networking)
  ❌ No vault VM (offline storage)
  ❌ No TAP bridges (no vmfw bridge)
  ❌ No inter-VM network isolation (all VMs share host NAT)
  ❌ No nftables policy between VMs
  ❌ Host has default route (not isolated from VMs)

Storage / Persistence:
  ❌ No persistent /home disks for VMs
  ❌ No disposable VM support (overlay-only)
  ❌ Created VMs don't persist in flake (stubs in ~/.microboxes/ need manual copy)

GUI / Desktop:
  ❌ No SPICE/virt-viewer integration (can't see VMs as windows on labwc)
  ❌ No colored borders on VM windows (no labwc rules)
  ❌ No virtio-Wayland (seamless apps)
  ❌ No panel (optional but mentioned in Flow Plan)

Host Minimization:
  ⚠️ NetworkManager should be removed
  ⚠️ Extra packages (SSH, PipeWire, git, gh, vim, htop, wget, curl) not minimum
  ⚠️ allowUnfree not needed for this setup

Code Structure:
  ⚠️ Redundant personal in flake.nix nixosConfigurations
  ⚠️ No separate base.nix / presets / vms/ modules (flatter than spec)
  ⚠️ Repo layout differs from Flow Plan Section 7 (but functionally OK)

Bugs / Issues:
  ❌ deploy.md typo: says .#host, should be .#nixqubes
  ❌ hardware-configuration.nix commented out in flake.nix
  ❌ GUI tries to "nix run .#personal" for disposables (may not work)

BUILD READINESS
================================================================================

Can you build this? YES.
Will it work? YES (Milestone 2–3 level).
Is it production-ready? NO (lacks isolation, SPICE, security model).
Is it a good foundation? YES.

To build:
  1. Supply hardware-configuration.nix (generated on target machine)
  2. Uncomment line in flake.nix
  3. Fix deploy.md typo if following docs
  4. Run: sudo nixos-rebuild switch --flake .#nixqubes
  5. Wait ~20 min (first build) for host
  6. Reboot
  7. Log in as admin/changeme
  8. Manager GUI should appear on labwc (or launch: python3 scripts/gui-launcher.py)
  9. Click Start on personal VM → watch it boot
